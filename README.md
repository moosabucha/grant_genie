Project : Grant Genie – Research Funding Match Platform 
Description : An AI-based web platform that matches researchers with relevant funding opportunities using TF-IDF, RapidFuzz, and Hybrid algorithms. 
How to Run :
1. cd backend 
2. source venv/bin/activate 
3. python3 app.py 
4. Open browser: http://127.0.0.1:5000 
Requirements :
pip install -r requirements.txt
